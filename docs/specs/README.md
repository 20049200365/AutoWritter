## 模块全景（8 个）

| 模块 | 名称 | 一句话职责 | 依赖 |
|---|---|---|---|
| M1 | 数据与领域层 | Schema、Repository CRUD、撤销窗口、统计聚合 | 无 |
| M2 | 索引与检索服务 | 切块、FTS、实体共现索引、检索、分层摘要 | M1 |
| M3 | Agent 编排引擎 | LLM 网关、tool loop、单章流水线、SSE | M1 M2 |
| M4 | Skill 系统 | Skill 包加载/注入/管理 | M1 |
| M5 | 偏好学习 | 接受/驳回事件、画像蒸馏、评审权重 | M1 |
| M6 | Web API 层 | REST 路由装配、错误规范、静态托管 | M1~M5 |
| M7 | 前端工作台 | 七大模块页面 + 生成工作台 + 划选编辑 | M6 |
| M8 | 章节后处理 | 摘要/抽取/建议队列/大纲对账流水线 | M1 M2 M3 |

## 开发轨

- 轨 A：M1 → M2 → M8（数据 / 检索 / 后处理）
- 轨 B：M3 → M4 → M5（Agent 能力）
- 轨 C：M7（前端，先对 Mock）；M6 为装配层，随各模块路由就绪而增长
